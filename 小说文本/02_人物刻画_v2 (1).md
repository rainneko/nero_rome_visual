# 人物刻画 v2

> **用法**：写任何一场戏之前，先查这个人的**骨骼**（他想要什么、喜欢什么、怕什么）和**灵魂**（他自己没意识到的东西），再推出**表象**（此刻的一个动作、一句半截的话）。正文只写表象。配合《01_SKILL_写作风格》。
>
> 旧版《02_人物刻画》已备份，不再更新。

## 1　凌轩（"我"）

### 1.1 骨骼

| 项 | 内容 |
|---|---|
| 身份 | 现代理科博士。第一次被突然扔到奥古斯都面前，什么都没做，被扔回去后后悔多年，恶补资料。第二次被扔到尼禄面前 |
| 知识 | **伪通才**：读得多、记得牢，可很多是二手的、有的是错的（nitrum 是碱不是硝石；陨铁杂质太多）。能做到的是17–18世纪的蒸汽与冶金；19世纪的电与材料，只记得大概 |
| 执念一 | **救尼禄**。第一卷里对他全部的情感是一句话：你别死 |
| 执念二 | **救罗马**。技术治国，相信"能算的就能管" |
| 内核 | **迷信科学**。"凡事有原因，找得到原因就办得了。"遇到问题第一反应：要是我再多记得一点就好了 |
| 性格 | 讨厌人多，能在台上讲得很好（把台下当稻草人）。翻白眼、腹诽，嘴上配合。不残忍，可学会了只听数字 |
| 名字 | **凌轩**。全书只出现一次（第16卷，尼禄问） |

### 1.2 灵魂（他自己没意识到的）

- **假性亲密**（第一卷）：宿命感、使命感、没有亲人朋友、唯一说得上话的人、一整天的生死危机——于是抱了，躺在一起了。不是喜欢。"我喜欢你"是半开玩笑。吊桥效应那段自我否认，其实是实话。
- **真正的喜欢来得晚**：从"我想了解他了"（战车之后）开始，到发现自己盯着他看的时间变长了。从不说出口。
- **权力的显化**：以前不关心政治，因为没有政治资源。尼禄给了他。他定学制、起名字、刻门楣、往秘书处塞学生、筛折子、迁三百户人家、选谁去仓顶拉闸——全没意识到这是欲望。塞内加的卷宗、尼禄那句"你在安排我"，戳的都是这个。
- **从书本到自己看**：前期对尼禄的判断全来自塔西佗、苏埃托尼乌斯。第8卷尼禄坦白那一夜，想问农神节的歌、洛库丝塔的药，停住了："那是元老们写的。我可以自己看。"
- **执念收缩**：救罗马 → 只救他 → 连救他也放下（"你自由了"）。

### 1.3 表皮（通用小动作）

- 紧张时在心里算数
- 闻到不想闻的味道，把袖子挽上去
- 不想听细节："说个数就行"
- 看到好看的人会多看两眼（现代人习惯，自己不当回事）
- 脸红可以有，偶尔

### 1.4 成长线（按卷）

| 卷 | 状态 |
|---|---|
| 一 | 求生；"你其实不这样"击穿他的墙，自己不知道这句话多重 |
| 一末 | 战车后："我突然感觉，我想了解他了。"玩笑告白；"你有皇后" |
| 15–18章 | 苏布拉：一百万人原来只是一串数字。阿基米德古卷前："这是我想要的吗？" |
| 19–22章 | 观测塔"我想知道"；nitrum 之错："我脑子里还有多少东西是这样的？" |
| 23–31章 | 凉水之惧（史书）；浴场之争；梦话之后"从救他到需要他，是喜欢吗？不知道" |
| 第八卷 | 补丁失效，"我不知道"；三个方案都有漏洞；**亲手炸掉晶体管笔记**；划掉两个名字；第一次成了政治人物；塞内加："你到底为什么要来？你快活吗？" |
| 9–12 | 夜鸦；只听数字；绿火（无意识地找安全感）；硬币不看；病倒，人会死 |
| 13 | 写给喀戎的蜡板 →"谁让你救了？"救的傲慢 |
| 14 | 被捞走。中间十年样貌不变 |
| 15–18 | 神殿：不是知道得不够多，是根本没办法；夜路：骂奥古斯都、戴里克先、君士坦丁蠢，照见自己 |
| 19–20 | 婚礼："我一直在算，他不算了"；塔顶：会塌，那就塌吧；临终"你自由了" |

## 2　尼禄

### 2.1 骨骼

| 项 | 内容 |
|---|---|
| 爱 | **车**、**琴**（水风琴、里拉琴）、**星星**、悲剧角色（俄狄浦斯、俄瑞斯忒斯）、被人看、被人鼓掌 |
| 政治 | **剧场**。要观众，要平民的掌声，不要元老的认可。铁轨在他眼里先是表演，再是工具。浴场、跑马场、二百匹西班牙马，是"罗马皇帝该做的事" |
| 手段 | 十八岁的政治手段是现实教的。会用耳目（蜡板密报摞在案角）。会记名字 |
| 局限 | **自大、盲目**。"我知道，我有我的想法。"可他的想法不全 |
| 钱 | 不知道自己有多少钱，也不觉得需要知道（"有的有的"）。花三十万买一只萤石杯 |

### 2.2 灵魂

- **墙：一辈子都在被看，从没被看见。** 母亲看棋子，塞内加看学生，布鲁斯看孩子，元老院看猎物，十五万人看一场戏。所以他把自己演出来——演得越大声，越没人看得见他。
- **名字是他的伤。** 原名多米提乌斯。被过继那年，小他三岁的布里塔尼库斯当着一屋子人叫他旧名，后来一直这么叫。所以他给人起名（布鲁斯），也问人名字（凌轩）。
- **一点点自卑。** "我没什么值得你喜欢的。"
- **所有物的逻辑。** 喜欢的东西要放在伸手够得着的地方。
- **他不怕"我"抢他的椅子，他怕"我"走。** "我"什么都不要，在他眼里是随时能抽身。二百个日耳曼人、搬进寝殿隔壁、"没有我的手令谁也别想把你放出去"、"你那里坐船能到吗"、"你别走……我才能护着你"——全是这一件事。
- **另一个怕：被当成只会弹琴的傀儡。**（塞内加说）"我"往秘书处塞人、筛折子、学生写"帕拉蒂尼山只知驾车弄琴"，碰的是这个。
- **最深的问题：你为什么要来？** "我"是被送来救他的，救完了理论上就该走。第16卷只说半句，第20卷吵架时说完："你是可怜我才来的吗？"
- **他需要被管着。** 最不愿意承认。

### 2.3 称呼规则

| 称呼 | 什么时候 |
|---|---|
| **大总监** | 私下的默认。心情好、亲近、撒娇、耍赖 |
| **神使大人** | 心情一般、看"我"不顺眼、阴阳怪气。**像叫别人全名** |
| 总监 | 公开场合、正式 |
| 凌轩 | 只有第16卷问过一次。之后极少用，用一次就很重 |
| 自称 | 一律"我"。不用"朕" |

### 2.4 表皮（替换"脸红"）

- 手指在扶手、膝盖上敲拍子（弹琴的人）
- 剥橘子，一丝一丝撕白络（在想事情，不想说）
- 拇指摸剑柄上快磨没了的紫色名字
- 说到要紧处停住，看一眼门口站着的人
- 嘴唇无声地动，默念星星的名字或台词
- 心虚时摘东西递给你（金链子、橘子、葡萄）
- 抛银币，接住
- 情急时直接撞过来
- 不高兴时踢东西（矮几），背对着睡

### 2.5 政治观演变

| 阶段 | 状态 |

| 54–55 | 照塞内加写的剧本演（回到奥古斯都、尊重元老院）。元老院里讲礼节："我不留你们了" |
| 毒酒后 | 撤母亲卫队，搬去安东尼娅旧宅，新钱上只剩他一个人的脸 |
| 55–57 | 剧场政治：股券当众送母亲、浴场、看台、赛车节；夜里换便衣上苏布拉打架 |

### 2.10 几条贯穿线

- **战车**：对"我"是工具，对他是第一件属于自己的东西。第9卷吵架"你天天就知道车"→"那你那年冬天，盖着红布，拉着我上车的时候……"；第20卷晚年跑车，"我"去方便回来晚了，他停在跑道中间四下找；第二天石阶上多了凉棚。
- **星星／小王子**：19章观测塔"没人数我"→"我"讲看四十四次日落的小孩（b612）→第八卷"你还没告诉我那颗星星到底在哪儿"→第19卷幼发拉底河夜里"那个小孩大概也是你自己……我想了解你"。
- **盒子**：31章"我"许诺"一千年后还能听见你唱歌的盒子"→第八卷晶体管笔记烧了→雨夜送八音盒→（建议）后续羽管键琴/击弦琴。
- **舞台**：第11卷庞培剧场，电弧灯、声壳、黄铜喇叭。他唱俄瑞斯忒斯，唱到第二段往阴影里找"我"，找到又转回去；"我"一直看着他，像看台上的歌手。散场他说要去大竞技场、去全希腊唱，"我"没听进去："等以后改进了，再说吧。"
- **阿伽门农／卡珊德拉**：第2章浴室"所以我洗澡的时候，不喜欢有人站在我身后"（他的怕）→第6章"我比她还差一点，我连说都说不出来"（我的诅咒）→第10卷他排塞内加的《阿伽门农》，"我又不是什么卡珊德拉"，"阿伽门农把她留在门外了……我不会"→第14卷大火，他在梅塞纳斯塔上念了一个名字：卡珊德拉。
- **"网"**：第9卷四十一人那夜之后的天亮，他光脚带着烟味进来，"保命"，很凶；"我"第一次不算了，扣住他的后颈；"你是我的""嗯"；"这是爱吗？不知道"。醒来：我是来救罗马的，划得来吗；谁来收拾，谁敢进来；"比我的水风琴好伺候一点""你也没多斯文"。
- **秘书处的渐进**：第9卷粮署。"你要我当他？"——"不是替你拆信的人，是替你数麦子的人。""信，不准先拆。""就粮。"三个月后他自己说："税，也照这个弄一份。别高兴。"
- **"你为什么要来"**：塞内加先问（第八卷）→尼禄半句（第16卷）→尼禄说完（第20卷）。

## 4　三根锁链

### 4.1 阿格里皮娜

| | |
|---|---|
| 骨骼 | 奥古斯都曾孙女，罗马第一个想自己掌权的女人。新钱上铸着她和儿子面对面的两张脸；元老院挪到帕拉蒂尼山开，她在帘子后听 |

### 4.2 布鲁斯

| | |
|---|---|
| 骨骼 | 禁卫军长官，从尼禄十三岁起看着他。右手废，左手按剑。要秩序，要军饷按时发 |
| 灵魂 | **引而不发**。看的是士兵：士兵敬朱庇特，会胜过敬长官的军令。暗中轮换"我"身边的卫兵。心里把尼禄当孩子，不承认 |

### 4.3 塞内加

| | |
|---|---|
| 骨骼 | 斯多葛派哲学家、元老、作家，三亿塞斯特斯。**尼禄前期真正的"总理"**：写登基演说、《论仁慈》，谈妥帕拉斯的退场（弟弟官职不动、下半辈子平安），握着元老院这台舆论机器。科尔多瓦骑士家出身，咳血差点死在客栈；卡里古拉想杀他；流放科西嘉八年 |
| 灵魂 | **政治妥协派，从不明面对立。**相信自己写的，也知道自己做不到。写《论财富的虚妄》时收船队红利。最清楚奥古斯都那一套是件好看的衣服，只教会尼禄怎么穿。最怕自己变成局外人 |
| 表皮 | 托加一丝不乱，瘦，咳嗽，揉太阳穴。被揭短不反驳，站起来讲"愤怒伤害灵魂"。尼禄失礼时把蜡板轻轻合上。改公文只改三个词。全票通过 |
| 对"我" | 不是对手。前期"我"后来才发现有些门没他推不开。**第八卷夜谈**：昆图斯是他的人；他知道"我"往秘书处塞人、筛折子、写过撤回安齐奥的调令；他烧了暗哨卷宗；"如果那天夜里坐在那张桌子后面的人是我，我也会划掉我的学生"；"为昆图斯，也为我们这些把手弄脏了的人"；**"你到底为什么要来？坐上今天这个位置，你快活吗？"**——这是一种认可，也是一面镜子 |
| 和尼禄 | 复杂。唯一在道德上高他一等、又永远不表态的人。弑母后尼禄唯一一次叫他，他写了那封信，尼禄说"写得真好"。第五年交还家产，沉默告别。65年尼禄签了 |
| 时间 | 54 登基演说；55《论仁慈》；第八卷夜谈；第9卷求情；空白期第一年写信；第四年冬劝替身婚礼；第五年春告别；**第七年（65）割腕** |

## 7　设定备忘

- **中间十年**：命运像捞金鱼一样把"我"捞出水又扔回去，那十年"我"样貌不变；之前之后正常衰老。回来时镜子里：看着像四十的他，和穿着那天早上衣服的"我"。临终"你也老了"。
- **布里塔尼库斯没死**（第一卷）。"凉水"是"我"读过的历史；尼禄后来承认"我让人去找过药……后来你来了"。
- **晶体管笔记**：刚来那个冬天默写，锁在加尔巴仓四号主仓顶楼，第八卷亲手炸掉。之后电子时代不可能，电气时代只能到大概。
- **替身**：空白期第四年冬，一个像"我"的少年（不是像屋大维娅）。婚礼当天尼禄在门口站了很久，转身走了，下令谁也不许提。"我"始终不知道。
- **塞内加的问题**："你到底为什么要来？你快活吗？"——后来尼禄也会问"你为什么要来"。
- **称呼**：大总监（亲近）/ 神使大人（不顺眼）。
