# 02 · 史料、时代过滤与坐标

## 1. 研究顺序
1. **时代快照**：写下"故事开始那一年"城市的样子：城墙、河道、山丘、主干道、大型公共建筑、水渠。
2. **不许出现清单**：列出这一年之后才建的著名建筑。罗马（公元 54 年）例：
   斗兽场（70–80 年）、图拉真广场、卡拉卡拉浴场、哈德良万神殿的穹顶（约 125 年；54 年的阿格里帕万神殿是长方形门廊式）、
   图密善的帕拉蒂尼大宫殿。故事改写了历史时（尼禄活了下来），还要列"因故事而永远不会出现"的建筑。
3. **坐标表**：以中心地标为原点，量出每个地标的相对位置（本案例的罗马广场为原点：卡比托利欧山朱庇特神庙在西约 250 米，
   帕拉蒂尼山在南偏东约 350 米，大竞技场在南约 650 米，台伯岛在西南偏西约 650 米，庞培剧场在西北偏西约 1.1 公里，
   奥古斯都陵在北偏西约 1.7 公里……）。
4. **逐栋核对**：每栋地标查一部可靠的地名词典（罗马用 Platner《古罗马地名词典》，LacusCurtius 在线版），
   记下建造年份、形制、朝向、尺寸。
5. **复原方案的取舍**：学界有争议时，选一个并写明（例：克劳狄神庙在 54 年刚动工；尼禄的宁芙水景墙在 59 年以后，
   属于空白期状态）。顾问 agent 给出的"宽百米、高 15 米"这类数字，查不到出处就当作设计选择，不当作史实。

## 2. 来源分级

| 级别 | 例子 | 能用来做什么 |
|---|---|---|
| A 一手/考古 | 发掘平面、大理石平面图残片（Forma Urbis）、水渠测量 | 平面、尺寸、朝向 |
| A- 学术词典与专著 | Platner 地名词典、专题论文（如罗马水道研究期刊） | 年代、形制、争议 |
| B 学术复原模型与版画 | 吉斯蒙迪石膏模型（4 世纪的罗马）、皮拉内西版画与平面 | 密度、体量、质感；注意时代 |
| C 游戏与概念艺术 | Anno 系列、刺客信条 | 只借氛围和配色 |
| D 维基百科 | 各建筑条目 | 入口和交叉核对，不单独作为依据 |

## 3. 用数据做大尺度
- 帝国地图：Ancient World Mapping Center（AWMC）的 geodata（ODbL，必须署名，衍生数据同样 ODbL）+ Natural Earth 的海岸和河流（公有领域）。
  本案例做出 38 个行省（每个标治理方式、已知总督、驻军）、28 座城市、19 个军团驻地。
- 城区：真实的山丘、河道和主要道路先成为"骨架"，地标贴在骨架上，民居最后填。

## 4. 标签规矩
- 地名卡片写清 **【史】**（史实或学界估计）和 **书中**（小说设定）。例：
  "【史】尼禄生在安齐奥，这里的皇家别墅沿海岸展开；这座海角堡垒是书中的样子。"
- 引用小说原文要逐字。
