# 03 · 参考图：怎样找到"对的图"，怎样量化地使用它

朱庇特神庙之所以一次就做得好，关键是**参考图对**：时代对、视角全、细节清楚，又有史料可以交叉核对。
反过来，用错图（比如后世的城市模型）会让整片城区"时代穿帮"。

## 1. 六项打分（每项 0–3 分，满分 18）

| 指标 | 3 分 | 0 分 |
|---|---|---|
| 时代吻合 | 正是故事那一年，或可以明确剔除后世部分 | 时代不明或明显是后世 |
| 来源可信 | 考古平面、学术复原 | 来历不明的网图 |
| 视角有用 | 同一建筑有正面、侧面、鸟瞰中的两种以上 | 只有局部特写 |
| 清晰度 | 宽 ≥ 1500 像素，细节清楚，无大水印 | 模糊、压缩重 |
| 可配准 | 画面里有 ≥ 4 个分散的已知地标，或有比例尺、柱距可量 | 无法换算尺寸 |
| 文本吻合 | 和小说描写一致（"门口两棵老伞松""干水池"） | 和书冲突 |

- **核心资产**：至少 2 张总分 ≥ 12 的图（不同角度）+ 1 张平面。
- **氛围图**（游戏截图）：可以低分，但只用于配色和构图，写进清单"只借氛围"。
- 每张图写进 `refs/manifest.csv`：编号、来源链接、许可、时代、用途、**要忽略的部分**、分数。

## 2. 去哪里找（搜索配方）
- 拉丁名 + reconstruction / model；意大利语 ricostruzione / plastico；学者名或模型名（Gismondi）。
- 平面：Forma Urbis 残片（斯坦福数字大理石平面图项目）。
- 遗存与版画：皮拉内西数字项目（Piranesi Digital Project），18 世纪版画常常画出今天已毁的墙体。
- **用考古术语搜**：大众叫法搜不到时，换专业叫法。例："尼禄瀑布墙"搜不到复原图，
  学界叫"尼禄的宁芙水景墙"（Ninfeo di Nerone）；常见复原模型画的却是韦斯帕芗重建后的神庙——又要做时代过滤。
- 作者自己找到的图常常最好：让作者每张图附一句"我要它的什么"，主建造把这句话写进清单。

## 3. 量化使用参考图

### 3.1 从鸟瞰图量城市密度（本案例的方法，脚本见 `scripts/density_from_reference.py`）
1. **按颜色分类**：每个像素分为陶瓦屋顶 / 浅色墙面 / 树木，排除水印区域。
2. **网格统计**：按 12 像素网格统计屋顶占比，模糊平滑。
3. **配准**：用 9 个位置确定的地标做投影映射（单应矩阵），把图片坐标换成地图坐标，得到 64×64 密度图。
4. **检查误差**：叠图检查。本案例地标误差 7–62 像素；9 个地标都在城东和城中，西边是外推的，河道在西北明显偏。
   所以没有照搬，而是把它和"离中心距离曲线"按 **6:4** 混合。
5. **结果**（屋顶覆盖率随离广场距离）：0–400 米 0.73，400–800 米 0.66，800–1200 米 0.56，1200–1600 米 0.36，
   1600–2200 米 0.18，2200 米以外 0.06。据此分出极密（约 1 公里内）、普通（到约 1.4 公里）、零散房屋加花园（1.4–2.3 公里）、农田。

### 3.2 用颜色统计对齐画面（学 athenaion）
athenaion 用代码程序化生成整个古希腊世界、没有外部素材；它的 `refs/` 里有 9 张参考图，工具里有
截图、裁剪、颜色统计、饱和度统计、烘焙等脚本。做法可以借：**每个特征都对应一张编号参考图**，
截图后统计画面颜色和饱和度，与参考图比较，再调材质和光照。

### 3.3 从图里读"规则"而不是"复制"
- 民居：数窗宽、层数、屋顶类型比例、阳台比例 → 变成生成规则（例：平顶比例极密区 18%、普通区 12%）。
- 立面：常见装饰（檐口浅色饰带、齿饰、壁柱、窗楣山花、网格石砌加砖带）→ 变成着色器里的花纹。

## 4. 时代过滤实例
- 吉斯蒙迪模型展示的是约 4 世纪的罗马：用它的密度、屋顶质感、街区肌理；建筑清单要剔除斗兽场等后世建筑，
  剔除后的空地多半当时是民居。
- 一张"罗马三世纪"的图里有一座直通皇宫的高架水渠：核实后，尼禄拱渠确有其事（克劳狄水渠的支线），于是做了，
  并按书中设定"尼禄活着，水一直送到宫里"安排在后期状态出现。
