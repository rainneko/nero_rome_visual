# 08 · 阅读体验

## 1. 布局
- 桌面：正文在右，约 38–40% 宽，半透明羊皮纸底；相机做视口偏移，让场景主体落在左侧 60%。
- 手机：场景固定在上方约 40%，正文在下。
- **全屏阅读**：正文铺满，场景只做背景；可选宋体 / 楷体 / 黑体，字号可调，设置记在浏览器里。

## 2. 面板分层
1. 第一层（一直显示）：年代标题、资源图标、页面切换（城市 / 子场景 / 帝国地图）。
2. 第二层（可折叠分组）：视角、时间与季节（默认展开）；显示、声音、导入（默认收起）；小地图单独折叠。
3. 第三层："全部收起"成一条小栏。避免重复按钮（我们出过两个"地名"按钮）。

## 3. 资源栏
- 图标 + 短数字（"+20""−10""≈3k""7天"），正数绿、负数红；悬停显示圣经里的完整文字。
- 图标用透明背景（作者给的白底图要抠图）。复合项（水泥 / 玻璃）分开。

## 4. 文字与城市的连接
- **地名词典**（本案例 62 条）：每条有关键词、机位或标签、是否自动飞行、所属场景（罗马 / 安齐奥 / 奥斯提亚）。
- 三种链接：点击飞行、背景知识卡片、自动飞行（只在含移动动词的段落触发）。本案例全书命中 581 处（308 点击、216 卡片、57 自动）。
- **限量**：每章同一个词最多高亮 2 处。**分场景**：逐段判断当前在哪个场景，避免把安齐奥的"行宫"链到罗马。
- **人工审批**：把所有命中导出成表格（章节、原句、词、链接目标、类型、✓/✗），交作者逐条批。

## 5. 段落触发与章节闸门
- 触发：写一句原文 + 机位 + 事件。例：
  - "阿波罗祭典那天，战神广场的看台上坐满了人。" → 飞到战神广场，出现临时木看台和蜂蜡皮囊。
  - "大竞技场在帕拉蒂尼山和阿文提诺山之间的山谷里。" → 飞到大竞技场，红色热气球出现，战神广场的撤掉。
  - "尼禄给我的那处别庄，在埃斯奎利诺山的东坡上。" → 飞到荒废的元老花园。
- 闸门：第 7 章起才有青铜规矩柱，荒废花园同时消失。
- **示例文字里也放这些触发段落**，不导入全书也能演示。

## 6. 导航
- 小地图：画出山丘、河流、地标和当前视角，点击飞过去。
- 键盘：W/S 前后，A/D 左右（实测过一次左右反了），Q/E 转向，R/F 远近；方向键同样可用。
- 帝国地图里放"返回城市 / 子场景"按钮；遮罩层的样式不要盖掉 `hidden`（`[hidden]{display:none!important}`）。

## 7. 声音
合成的八音盒容易"坏掉"般诡异；让读者上传自己的音乐文件（存在浏览器里）更稳。风铃之类短音效可以合成。
