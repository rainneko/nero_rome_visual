# 14 · 从小说文本推导功能分区（以安齐奥为例）

作者对安齐奥的第一版不满意："既然是行宫这么多居民区干什么。"问题出在建模前没有回答"这个地方是干什么的"。

## 1. 先把原文里的这个地方全找出来
- 让一个便宜的子代理（Haiku）在全书里搜地名，每处读前后十几行，写一份报告：时间线、内部地点清单（名称原文·功能·位置关系·出处行号·不超过 40 字的逐字短引）、人员、地形描写、矛盾点。
- 主控**抽查关键原句**（子代理会漏行、会把别处的场景算进来）。
- 安齐奥的结果：海边行宫兼港口；主殿沿悬崖层层上盖、每层朝海长廊；最高处是观景台和观测塔；三面绝壁的侧殿只有一座窄桥；悬崖工坊、铅室、葡萄藤凉亭；崖下水轮；悬崖马道；日耳曼卫队；南面港口。**没有写居民区**，也没有写花园。

## 2. 写分区表（每行：区·功能·原文依据·参考图依据·核心资产）
| 区 | 功能 | 依据 |
|---|---|---|
| 城门与卫营 | 唯一陆路入口，铁门、哨卡、日耳曼卫队营房 | "调两百个最好的日耳曼人去安齐奥，修铁门，设两道哨卡。" |
| 下层花园 | 柏树大道、花坛、圆形柱廊花园 | 书中未写，按参考图和罗马别墅惯例补，标明 |
| 工坊院 | 工坊大厅、铅室、凉亭；崖下水轮与镗床 | "悬崖上的工坊"、"工坊后面的空地上……大槽房"、"临海的天然玄武岩" |
| 翼楼台地 | 每层两侧翼楼，楼外是朝海长廊 | "每一层都有一条朝海的长廊" |
| 主殿 | 回廊正中青铜祭坛、寝殿、露台 | "回廊正中的青铜祭坛"、"寝殿"的玻璃窗 |
| 山顶观景台 | 全宫最高处，观测塔与铁矛 | "最高的那一层，原本是先帝们看海用的观景台" |
| 侧殿岩 | 三面绝壁、窄桥、铁门、暗室 | "三面绝壁，只有一座窄桥连着主宫" |
| 港口与镇子 | 渔船、栈桥；镇子放在陆地上 | "岬角的南面是港口" |

## 3. 再定地形和轴线
- 最高点放在尖端，**塔后几十米就是断崖**；花园、台地、主殿沿一条中轴逐级上升，台阶穿过每一级。
- 天然岩石只在墙外；墙内是砌筑台地（台地边就是城墙），自然地面处处低于台地，免得地面刺穿台地。
- 书里有而参考图里没有的（马道、海神龛、终点高台），和参考图里有而书里没有的（花园、圆形柱廊），都要在标签里说清来源。

## 4. 把分歧交给作者
例如原文"城建在一段向海里伸出去的岩岬上"暗示镇子在海角上，而作者要的是"海角上只有行宫"——
沙盘按作者的意图做，在报告里提一句，由作者决定要不要改一个字。
