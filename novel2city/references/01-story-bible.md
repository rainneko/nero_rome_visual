# 01 · 设定圣经（硬核设定）：怎样从一本小说得到它

城市里的每个数字、每栋建筑出现的时间，都要能追到一个文件。这个文件就是设定圣经。
本案例里它叫 `05_硬核设定.md`（约 1.6 万字），开头三行就定了规矩：

> **用法**：写到某一卷，先查这一卷的数字，正文里只露一两个，其余留在这里，保证前后不打架。
> **数字的来历**：凡标【史】的，是史料或学界估算的量级；标【设】的，是按【史】推出来的小说设定值。所有数字取整、取保守值。另一个模型给的数字逐条核过，对的留，偏的改（见文末）。
> **时间轴**：一行写完全书的年份节点。

## 1. 圣经要包含什么（按本案例的结构）

| 部分 | 内容 | 在城市里的用途 |
|---|---|---|
| 用法与数字来历 | 标签规则、取整规则、核对记录 | 让所有人用同一套规矩 |
| 时间轴 | 全书年份节点（到达 → 关键事件 → 空白期 → 回归 → 晚年） | 切分"时代状态" |
| 〇 基准 | 帝国人口、城市人口、财政总量、军饷、财产门槛、一斗小麦价格 | 数字的"换算感觉"（例：军团兵年饷 900 塞斯特斯，所以"五万银币一根梁"约等于 55 个兵一年的饷） |
| 一 建筑与工程跨卷进度表 | 工程 · 立项 · 开工 · 关键节点 · 完工 · 空白期状态 · 回归后 | 决定每个图层在哪些状态出现、出现成什么样（脚手架/完工/荒废） |
| 二 钱（三本账） | 国库、公社、私库：收、支、关键变化 | 顶部资源栏 |
| 三 资源与产能 | 焦炭、生铁、钢、水泥、玻璃、存粮…… | 顶部资源栏、工业区规模 |
| 四 人才与人口 | 学园人数、毕业生、工人 | 学园扩建、街区密度 |
| 五 地点表 | 见 `templates/places.csv` | 城市坐标 |
| 六 未决问题 | 作者还没定的事 | 不要替作者决定 |
| 附 修改记录 | 谁改了什么、为什么 | 防止"改回去" |

## 2. 从手稿到圣经：九步流程

1. **分块**：每块约 2 万字，相邻块重叠约 1 千字（防止切断一个场景）。长书分批做，避免额度用完。
2. **逐块抽取**：用第 3 节的提示词，输出 JSON：地点、工程阶段动词（立项/开工/完工/失修/烧毁）、日期与相对时间、
   数量与单位、钱的流向、资源与产能、人物与职务、**景物原句**（后面做地名卡片要逐字引用）。
3. **合并去重**：同一地点的不同叫法合并成别名（例："皇宫/寝宫/内殿"都指帕拉蒂尼山的宫殿；但安齐奥也有"行宫"，按场景区分）。
4. **统一时间轴**：把"第二年春天""三个月后"换成绝对年份季节。
5. **打标签**：每个数字标【史】（给出处）/【设】（写推导）/【书中】（写章节）。
6. **一致性检查**：见第 4 节。
7. **史学复核**：交给史学 agent，要求它对每条意见给出处和把握程度；主建造逐条核实，写进修改记录。
8. **作者审定**：作者逐条确认或改。没有作者确认的条目，不进 HUD。
9. **冻结版本**：`bible-v1.md` + 修改记录。之后的修改只追加，不覆盖。

## 3. 抽取提示词（逐块使用）

```
你在为一本历史小说整理"设定圣经"。只依据下面这段原文，不要补充原文没有的信息。
输出 JSON，字段：
places[]: {name, aliases[], kind: 史|书中|改, where_in_text, quote(逐字景物描写,≤80字)}
projects[]: {name, stage: 立项|开工|节点|完工|失修|毁坏|重建, when(原文说法), chapter, details}
numbers[]: {what, value, unit, when, chapter, quote}
money[]: {ledger: 国库|公社|私库|其他, in_or_out, value, unit, when, reason}
resources[]: {name, amount, unit, when, chapter}
people[]: {name, role, first_chapter, notes}
open_questions[]: 原文里前后矛盾或含糊的地方
原文：<<<……>>>
```

合并时再用一次提示词：给出所有块的 JSON，要求输出"冲突表"（同一事物不同数字、不同时间）而不是自己选一个。

## 4. 一致性检查清单

- 同一工程的阶段顺序是否合理（不能先完工后开工）。
- 产能增长是否可信（每个状态增长倍数列出来，过大就标红）。
- 钱：收支差与"超支/赤字"的文字描述一致。
- 人数：学园人数与教室、宿舍规模对得上。
- 地点：书里写"从 A 走到 B 用了多久"，和地图距离对得上。
- 时代：每个工程和建筑与真实历史年份对照（真实存在的，按史；书中新建的，按书）。

## 5. 圣经怎样驱动城市

- **时代状态**：时间轴的节点 = 状态边界。本案例 9 个状态：54–55、56、56–57、57、57 秋、57 冬（粮荒）、58、59–68（空白期）、68–100。
- **图层区间**：进度表的"开工/完工/空白期/回归后"直接变成图层的状态区间（例：南岸高炉 状态 3–8；
  污染令后迁下游 状态 5–8；琉璃塔四层烂尾 状态 7，晚年完工 状态 8）。
- **资源栏**：每个状态一行短数字（"+20""≈3k""2000"），悬停显示圣经原文（"收 850 / 支 830"）。
  书里没有数字的格子写一个短词（"数吨""试验""赤字"），不编数字。
