# 13 · 没有罗马那样的史料时：其他朝代、其他文明、虚构世界

罗马的运气在于：词典、复原模型、版画、考古平面都很多。换一个时代，资料会少很多。
流程不变，**换的是"证据从哪里来"和"规则怎么写"**。

## 1. 证据替代表

| 需要的东西 | 罗马用的 | 资料少时用什么 |
|---|---|---|
| 地点与年代 | Platner 地名词典 | 当时人的城市笔记、地方志、考古报告 |
| 平面与轴线 | Forma Urbis 残片 | 考古发掘的城墙、城门、道路；历代地图（注意年代） |
| 体量与密度 | 复原模型的鸟瞰 | 同时代的长卷绘画（有艺术变形，配准分只给 1）；同时代幸存的建筑群 |
| 立面与构造 | 学术复原图 | 同时代的营造规范；幸存的同期建筑 |
| 氛围 | 游戏截图 | 同上（只借配色） |

新增一个标签：**【推】**——由同时代类比推出来、没有直接证据的部分。卡片里写清"按某某类比"。

## 2. 例：北宋汴京（东京开封府）
- **文字锚点**：孟元老《东京梦华录》（成书于 1147 年，追记北宋末年的开封）——街巷、桥、酒楼、夜市的位置与生活。
- **营造规则**：李诫《营造法式》（1103 年刊行）——材分制模数、屋顶形式、斗拱等级 → 直接变成参数化规则
  （开间、进深、举折、屋顶类型按建筑等级取值）。
- **画面参考**：张择端《清明上河图》（北宋晚期）——街市密度、屋顶比例、桥、船、人群；它是长卷，透视和比例有艺术处理，
  用来数"每段街多少间铺面、几成是二层楼"，不用来量绝对尺寸。
- **幸存建筑**：晋祠圣母殿（北宋重修）等同期木构，用来定柱高、出檐、斗拱的大致比例。
- **不许出现清单**的做法相同：例如开封的铁塔（祐国寺塔）1049 年才建成，故事早于这一年就不放；
  今天的龙亭大殿是清代建筑，北宋时那里是皇宫。
- **规则改写**：屋顶多为青灰瓦，宫殿寺观用琉璃；民居一两层，酒楼可到三层；夜景是灯笼和夜市，比罗马亮，但仍是暖色点光。

## 3. 其他常见设定的资料入口
- 唐长安：坊市制（坊墙与坊门）→ 城市是一格一格的；考古报告给出城墙和主街宽度。
- 江户：屏风绘、浮世绘、町割图；木构町家、防火土藏。
- 维多利亚伦敦：1890 年代测绘地图、照片、社会调查地图；砖砌联排、烟囱、工业烟雾。
- 中世纪欧洲城镇：地籍图、城镇平面、手抄本插图；木骨架房屋、上层外挑。

## 4. 虚构世界（没有史料）
1. 选 2–3 座**类比城市**（例：港口 + 山城 + 帝都），每个特征写"借自哪里"。
2. 写一份**风格圣经**：材料、屋顶、层数上限、街道宽度、密度梯度、技术水平（决定"不许出现"什么）、夜间光源。
3. 手画或生成一张**骨架地图**（地形、河、城墙、主干道、地标位置），再进入同样的 P4–P9 流程。
4. 参考图打分时，"时代吻合"一项改成"风格吻合"。

## 5. 资料少时更要做的事
- 把每个不确定的选择写进圣经的"未决问题"，让作者拍板。
- 宁可少放、空着，也不要拿后世或别处的建筑凑数。
- 让史学 agent 专门挑"这里用的是哪个朝代的样子"。
