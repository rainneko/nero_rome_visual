# 07 · 光、天气、季节、夜景

作者最喜欢的就是明暗和日夜变化。这一部分要早做、做稳。

## 1. 昼夜关键帧
- 用一组关键帧（时刻 → 太阳高度角、日光强度、天空色、雾色、曝光）做平滑插值。太阳方位角固定一个好看的值（本案例 68°）。
- 每个时代状态有默认时刻（例：开篇是罗马广场的清晨）。
- 夜里不要用"把一切调暗"来表达；月光强度要低（本案例从 0.45 降到 0.17），曝光倍数接近 1。

## 2. 季节与天气
- 季节平滑过渡：草色、树色、花期、果实、雪粒子（细则见下）。
- 天气：晴、雨、雪、雾；雨天雾会把画面冲白，单独调雾密度。
- **文本驱动**：用正则扫描当前章节的文字（"下雪""雷雨""黄昏"），切换季节、天气和时刻；用户手动调节后锁定一分钟。

### 季节先看气候，不要套温带的直觉
- **先定气候类型**：夏干的地中海、季风、温带……它决定草哪个季节黄。
  罗马是夏干型：没人浇水的草坡在**盛夏**变成麦秆色，秋雨后**返青**，冬天也是绿的。温带直觉"秋天草黄"在这里是错的。
- **分"浇水的"和"不浇水的"**：宫殿、宅邸内院、神庙里有水源的园子四季常绿；只有野坡、荒地跟着干湿走。
  两套材质，加一个"浇水区"遮罩。
- **常绿打底，落叶点缀**：秋色来自落叶树。案例城内约 35 %，山坡约 45 %，河岸以杨柳为主。
  地中海的秋天来得晚、颜色淡：黄褐、褐色，很多树还半绿，不要枫叶式的艳橙。
  每棵树按哈希错开变色，不要同时变。
- **花期按季节递减**：春天最多；夏天转为灌木花（夹竹桃、石榴花）；秋天几乎只剩果实的颜色。
- **按主人种树种花**：
  - 皇家园林品种最多、花期最长，奢侈到冬天用温水催开玫瑰（塞涅卡《道德书简》122.8）；
  - 元老宅邸是绿篱、月桂、玫瑰；
  - 神庙基本铺地，种的是"神的树"（阿波罗的月桂、大母神的松），花只在节日以花环出现；
  - 平民是窗台花盆和无花果（老普林尼《自然史》19.59）。
  这一张表比随机撒树更能让读者认出"这是谁的院子"。
- 顾问 agent 给的精确比例、色号和页码，多半是"看起来像学术"的设计值。可以用，但要标成设计选择，核实不了的出处不写。

## 3. 古代夜景（顾问 agent 的批评，采纳后效果更好）
- 楼上窗户约 7% 亮、亮度低并轻微闪烁；底层约 12% 亮（店铺、酒馆）。
- 贵族宅邸外墙几乎全暗，内院亮。
- 火把队伍沿主路移动；神庙和宫门放火盆。
- 玻璃窗随故事进度增加，夜里亮窗也随之增加。

## 4. 后期
泛光、色调映射、暗角、移轴（城市像微缩模型）、可选的油画滤镜。测试模式关掉重后期。

## 5. 材质要点
- 没有环境贴图时，光滑材质会发灰：用天空生成环境贴图。
- 彩色釉面不要加金属度，否则颜色发脏。
- 光滑大圆柱看不出砖或瓷片：用几千片实例化瓷片拼，每片微小倾角和色差，阳光下会一片片闪。
