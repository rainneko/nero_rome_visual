# 第一人称 · 走上帕拉蒂尼山（2026-11-16）

第一版能走了：从鸟瞰下到帕拉蒂尼山的地面，用键盘和鼠标走，能上台阶和坡，能跳，墙、树干和灌木会挡路。
山上有禁卫军、释奴和少数元老，草地上有草丛和花，树和草随风摆，空中有飘叶。没有战斗。

## 怎么进、怎么出

* 进：右上工具栏「视角」里的按钮 **第一人称 · 走上帕拉蒂尼山**。鸟瞰正看着山上哪里，就落在哪里附近；否则落在山顶广场。
  宫殿和神庙的模型没到齐时会先等一下（提示「正在等宫殿和神庙的模型就位……」）。
* 走：`W A S D` 行走，`Shift` 快走，`空格` 跳，鼠标转视角（点一下画面锁住鼠标；不锁也可以按住拖），`Q E` 或左右方向键转身。
* 出：`Esc` 一次暂停（「继续走 / 回到鸟瞰」），再按一次回到鸟瞰；左上角也有「退出」。退出后阅读页、镜头、标签都回到原样。
* 准星对着七米内的人，下方会出现这类人的说明。

## 人物

| | 数量上限 | 样子 | 在做什么 |
|---|---|---|---|
| 禁卫军 | 14 | 锁子甲、带红缨的铜盔、红色椭圆盾、标枪、短剑 | 六个哨兵两两背墙站岗，其余成对巡逻 |
| 释奴 | 9 | 束腰短袍（颜色各异），手里拿蜡板 | 单人来回办事，或跟在元老身后 |
| 元老 | 3 | 白托加、紫条、深色皮靴 | 慢步走，身后跟一个释奴 |

* 【史】禁卫军（cohortes praetoriae）是皇帝的卫队，营地在城东北，每天有一个大队到帕拉蒂尼山当值。
  塔西佗记当值的士兵穿托加、暗佩短剑；这里画的是野战装束，为的是一眼认得出。这一点如果你想按史实改成托加，说一声就行。
* 【史】释奴（liberti）是获释的奴隶。克劳狄和尼禄两朝，皇帝的书信、账目和请愿都由宫里的释奴经办。
* 【史】元老托加里面是带宽紫条的短袍（latus clavus），脚上是元老的皮靴（calceus），清晨到宫里问安（salutatio）。
* 装束和器物都不晚于尼禄时代。人物是方块拼的低模，没有脸。

## 风、植物、地面

* 原有的树、灌木和花丛加了阵风摆动；只在第一人称里开，鸟瞰的画面不变。
* 绿色的地面（草地、草坡）上长出草丛，按季节有花；夏天枯黄的草地暂时不长。
* 空中有随风飘的叶子或花瓣，颜色随季节。
* 脚下 30 米内的地面加了近看的细节（土粒、石子、草地的深浅纹）。

## 是怎么做的

参考项目只看了做法，没有抄代码、模型、贴图或关卡（它没有许可证）。
城市的网格合并后不留在内存里，所以不能用射线求地面。这里是从头顶往下把人周围 96 米拍成一张「高度图」
（三次：一次正拍，两次斜拍，斜拍用来认出墙和屋檐下的地面），人每走 9 米重拍一次。高度和碰撞都来自场景里现成的地面和模型，
不依赖哪座建筑摆在哪里，所以以后改帕拉蒂尼的摆放不用改这里。代码在 `src/ui/fp.js`。

## 实测（无头 Chromium，Mac 显卡，1280×720）

* `npm run check` 通过；`npm run build:test && npm run test:boot` 通过（no page errors）；`node tools/test/bake-roads.mjs --check` 两项都是 up to date。
* `npm run build && GPU=1 node tools/test/fp-walk.mjs` 通过：点按钮进入、W 键走、拖鼠标转、空格跳起并落地、Esc 暂停、再 Esc 退出；
  再进去走八段共约 32 米，始终站在可站的地方；三类人物都在，草丛约 5400 丛。
* 帧率：鸟瞰 12–19 帧，地面约 30 帧（同一台机器、同一次运行里比）。落地 0.3–0.6 秒；头一次进入要编译着色器，量到过 8 秒。
* 风：同一处隔 0.9 秒拍两张，开风时画面有 3–6% 的像素变了，关风时是 0%。

## 已知的不足

* 手机和平板没有做（触屏上按钮是藏起来的）。
* 建筑是壳，进不去；门洞后面是空的。
* 锁住鼠标的那条路在无头浏览器里测不了，只测了拖动和键盘；要请你在自己的浏览器里点一下试试。
* 跳起来能上比台阶高一点的矮台（约 0.95 米以内），有可能跳到本来不打算让人上去的矮墙上。
* 说明文字会比准星慢半秒左右。
* 测试工具里「沿网格找最高处走上去」这一步，在草坡上有时走到一半停下（网格说能走，行走规则嫌太陡）。只影响测试工具，不影响操作。
* 画面滤镜保持原来的设置，地面近看的细节在滤镜下比较淡。
