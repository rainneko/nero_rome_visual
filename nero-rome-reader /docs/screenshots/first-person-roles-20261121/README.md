# 第一人称：细分的人物（2026-11-21）

代码在 `src/ui/fp-people.js`。山上的人不再只有三种，而是按身份、地点、时辰分开刷新。走近对准一个人，下方会出现他的身份和一段【史】说明。

## 山上的分区

| 区 | 是什么 | 谁在这里 |
|---|---|---|
| A 宫门前 | 两座宫殿正门 16 m 以内 | 哨兵、问安的元老和骑士、门客、轿子 |
| B 山顶铺地 | 露天的铺石广场和路 | 几乎所有人 |
| C 神庙区 | 阿波罗、胜利女神神庙周围 | 祭司、贵妇、元老、学者 |
| M 大母神庙 | 大母神庙周围 | 阉祭司（Galli）、弗里吉亚祭司、十五人祭司 |
| D 花园 | 露天的绿地 | 园丁、挑水的、贵妇、日耳曼卫队 |
| P 柱廊下 | 有顶但不在宫内 | 哨兵、释奴、学者 |
| I 宫内 | 宫殿地面层和内院 | 释奴、骑士官员、禁卫军长官、日耳曼卫队 |
| E 下层 | 宫殿范围内比地面层低 2 m 以上（地下层、通道、下沉院） | 只有搬运的奴隶、挑水的、释奴、巡逻兵、工匠 |
| F 坡道 | 山顶以下的坡和台阶 | 巡逻兵、信差、搬运的奴隶 |
| G 屋顶墙顶 | 高出宫殿地面 3 m 以上 | 没有人 |

元老、骑士、门客、祭司都不会刷在下层和屋顶，走路的直线也不穿过这两种地方。自动检查（`tools/test/fp-walk.mjs`）会数“站错地方的人”，不为零就报错。

## 角色（36 种）

* **军人**：禁卫军哨兵（成对靠墙）与巡逻（两人并排）、百夫长（横缨、葡萄藤杖）、禁卫军军团长、禁卫军长官（带一名释奴）、日耳曼卫队（长发蓄须、长裤，在花园和宫内）。
* **元老**：执政官（镶紫边托加，前面十二名扈从排成一列，只在清晨）、裁判官（两名扈从）、普通元老（带一名释奴）、年轻元老（两人同行）。
* **骑士**：骑士官员（短袍窄紫条、斗篷、文书卷，带书记）、富有的骑士（托加外罩染色斗篷，两名奴隶跟随）、普通骑士（来问安的客人）。
* **平民与释奴**：门客与请愿人（托加不那么白，清晨等在门外）、释奴书记、希腊学者／医生。
* **奴隶**：扛双耳瓶的、挑水的、园丁、信差（跑）、执灯的（傍晚和夜里）、随身奴隶、轿子和四名轿夫、工匠（公元 64 年大火以后才出现）。
* **祭司（分等级）**：十五人祭司团成员（托加拉到头上，身后跟祭童、吹笛人、宰牲人）、弗拉门祭司（尖顶皮帽）、占卜官（弯头杖）、维斯塔贞女（一名扈从）、大母神的阉祭司（彩袍、手鼓）、弗里吉亚主祭。
* **妇女**：贵妇（长裙、披肩拉到头上）和侍女。

## 时辰

* 清晨：问安的高峰。执政官、元老、骑士、门客、轿子都在。
* 白天：元老少了，奴隶、释奴、贵妇、学者多。
* 傍晚：赴宴的元老和富骑士，前面有奴隶提灯。
* 夜里：只有哨兵、巡逻兵、提灯的奴隶和个别释奴。

## 已知的不足

* 【史】当值的禁卫军在宫里其实穿托加；这里仍画成野战装束，为的是好认（说明里写了）。
* 人物是方块搭的，托加、斗篷只是大致的形状。
* 小说里有名有姓的人物没有做成路人；禁卫军长官等只写官职，不写名字。
* 执政官的十二名扈从走在窄处会挤成一团。
