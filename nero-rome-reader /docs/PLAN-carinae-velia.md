## 0. 先回答"是不是改成参考图里的豪华住宅"

**大部分是，但要分两种。** 参考图文件夹里有两类和这里相关：

| 参考图（`罗马风格参考/民居参考/`） | 画的是什么 | 用在哪里 |
|---|---|---|
| `市中心高密度-豪华住宅/`（2 张） | 3 层的连排豪宅：底层拱廊带店铺，二层拱形凉廊带花盆和阳台，红瓦坡顶带采光口，米色灰泥加红色勒脚 | **卡里奈的街面**。密度高，但豪华 |
| `贵族庄园豪宅参考/`（1 张） | 大型庄园：多院落、长柱廊、圆亭、花园，依山而建 | **韦利亚山脊上的大宅**和**埃斯奎利诺山的梅塞纳斯花园** |
| `市中心中高密度-中收入住宅/` | 中等收入连排 | 卡里奈和苏布拉之间的过渡带 |

所以不是"整片换成一种"，而是按位置分级。苏布拉区保持现在的高密度公寓。

**Gemini 说的、我们不采用的：**
- "奥古斯都早年住在卡里奈、离大地女神神庙很近"：苏埃托尼乌斯《奥古斯都传》72 说他先住在罗马广场边，之后搬到帕拉蒂尼。
- "整条山梁全是元老大宅"：太绝对，到公元 56 年仍有店铺和普通住户。
- "平民不能进"：罗马没有封闭小区，街道是公共的。

**小说里：** 全书没有出现"卡里奈""韦利亚""梅塞纳斯"。提到"埃斯奎利诺"20 次、"苏布拉"15 次，苏布拉是贫民区（第 5499 行），城东埃斯奎利诺与苏布拉交界是剧情里的城改地段（第 5821 行）。**所以苏布拉不能动，新的豪华区必须避开它。**

## 2. 现在代码里是什么情况

分区在 `src/scenes/rome/monuments.js` 的 `bzone`（约第 664–672 行）：

- 用一个位置函数决定每块地的类型：`mid`（中档）、`dense`（高密度公寓）、`ware`（仓库）、`domus`（带内院的大宅）。
- 苏布拉盒子 `SUB`：x 200–1050，z −950..−120。
- **注意命名陷阱：** 代码里的 `VEL` 是**韦拉布鲁姆**（帕拉蒂尼山西侧，x −400..−60，z 60..480），**不是韦利亚丘**。改的时候不要混。
- 在"核心"圆（以 (120, −160) 为中心、半径 1000）里，只要落在 `SUB`、`VEL` 或密度大于 0.74，就是 `dense`。你截图里那片密集公寓就是这个规则的结果。
- `domus` 类型已存在，但只在坡度和园林条件下出现（`rel>15 && gd<.3`），主要在山上，这一带基本不触发。
- 已有的 GLB：`rome_domus_a/b`（带园林平台的贵族宅邸）、`rome_insula_a/b/c`（公寓楼）。立面着色器已有"富人"档（见 `briefs/rome/facades.md`）。
- 大地女神神庙在 (638, −111)，在这一带。
- **长廊占位：** 你之前看到的那段"没头没尾"的有顶长廊，我还没找到它的生成代码（见 §6 的第 0 项）。

**这一带的大致范围（估算，第一步要用叠加图确认）：**
- 卡里奈：x 480–780，z −260..40（大地女神神庙周围，埃斯奎利诺山南坡）。
- 韦利亚：x 300–520，z 20..200（帕拉蒂尼东北角通向埃斯奎利诺的山梁）。
- 梅塞纳斯花园：埃斯奎利诺山上，地图上的标注"帝国学园"（`Horti Maecenatiani`，monuments.js 第 399 行）附近。

**风险：** 我们的地形在韦利亚处有没有山脊，我没有查。如果地形是平的（韦利亚后来被削平，如果高程数据来自现代地形，那里就是平的），就需要决定是加一道 8–12 m 的山脊，还是不做。
