# 城市生动感：参考图研究与首批资产

研究日期：2026-10-25。目标是保留现有城市建筑，补足工作、交易、取水和庭院使用的痕迹。以下优先级是针对当前项目的设计判断，不是历史遗址复原结论。

## 从本地参考图读到什么

- `60101791621695_.pic_hd.jpg`：画面有说服力的部分是连续街沿、路口停驻点、店铺前的遮阳、广场上的人群和物品。建筑之间有清楚的通行空间；沿街活动与广场活动有尺度差别。画中远处的宏大建筑不能直接搬到公元56年。
- 中收入住宅两张图：底层开口、铺门、门槛、遮阳和小批商品，让同一种住宅有不同用途。比继续增加整栋住宅模型更值得先补。
- 高密度豪华住宅三张图：内外有区别，外侧是连续城市街墙，里面是采光庭院；不同宅翼围成空间，门廊与楼上敞廊有重点，不是每层重复拱洞。
- 贵族庄园图与安齐奥五张图：柱廊不是只有柱子，还连接坐谈、看景、休息、供水和花木。庭院需要可以辨认的休憩角，不能变成没有用途的绿色矩形。
- 山上神殿三张图：台基、挡墙、台阶把人可达的活动面组织起来。大斜坡上不靠散放小物件制造热闹；本轮小资产只进入平稳且已有通行条件的地方。
- 剧场、跑马场、行政区总图、饮水桥和浴场也做了缩略图对照；本轮不再加大型纪念建筑。浴场及总图里的晚期形制不作为AD56的施工依据。

这些原参考图只在工作区本地阅读，没有复制到本轮交付目录。三张设计图均为内置imagegen新生成的原创概念，具体结构仍由任务书和审图决定。

## 从高到低的资产优先级

| 顺位 | 资产/使用场景 | 对当前城市的贡献 | 现状与决定 |
|---|---|---|---|
| 1 | 成组临街商摊：棚、柜台、货物、秤、存货 | 从中距离就能认出买卖活动；有商品类别和商贩通道 | 原有柜台/棚是独立小物。新做 `rome_market_pair`，少量布置在街道拓宽处 |
| 2 | 取水与街角停驻点：水槽、罐、坐凳、邻里小祠 | 有日常聚集的理由；街角不再只是空地 | 已有 `rome_lacus/compitum`，优先改其布点与组合，暂不重复造水槽 |
| 3 | 烘焙工作间：炉、石磨、桌、粮袋、面包 | 让普通民居区出现能辨认的生产功能 | 新做 `rome_bakery_bay`，开敞工作间；不把庞贝79年的某房间说成罗马56年的原样 |
| 4 | 贵族庭院休憩角：爱奥尼柱、坐凳、半身像、桌、盆栽 | 从“有花园”进到“主人在此接待和休息” | 新做 `rome_garden_exedra`，只放已有完整、低落差的庭院 |
| 5 | 仓门装卸组：封口大罐、成摞木箱、天平、搬运板 | 仓库从重复屋顶变成物流场所 | 已有车、酒罐；下一批补货堆组织和仓门组合，不在路中堆货 |
| 6 | 小祭坛的使用物：花环、陶灯、供盘、少量花盆 | 让小神龛与祭祀区有尺度层次 | 低频、靠边；不在每个空地都建神庙 |
| 7 | 外立面生活细节：可收铺板、百叶、褪色壁画、绳挂 | 同类街墙出现用途和主人差异 | 复用现有立面规则，避免再次普遍铺横竖线/每层拱洞 |
| 8 | 小尺度道路细节：排水边槽、补石、磨损门槛 | 增强道路触感，需近景才明显 | 更多应由材质/少量几何完成，不用大量独立GLB铺城 |

活动人物也能提高生动感，但应围绕这些场所使用现有人物实例系统。当前批次不新增骨骼角色或全城独立灯光。

## 史料边界

- 【史】庞贝考古公园[官方指南](https://pompeiisites.org/wp-content/uploads/A-Guide-to-the-Pompeii-Excavations-2.pdf)的印刷页98介绍磨粮与烘焙设施的结合、火山石磨；此处只采用生产技术线索。它没有证明本设计在AD56罗马某个坐标存在。
- 【史】公园[Roman Housing](https://pompeiisites.org/en/pompeii-map/analysis/roman-housing/)介绍围柱庭院、彩绘室内与带雕塑喷泉的花园；贵族与普通住宅的空间配置不同。
- [Getty Villa Gardens](https://www.getty.edu/visit/villa/top-things-to-do/gardens/)说明其古代原型与重建部分；作为庭院功能和装饰组合的辅助资料，不能把现代博物馆的全套细节当作56年实证。

市集组合、烘焙间布局、休憩角以及精确放置位置都是本项目设计。未从游戏截图提取纹理或网格；概念图如出现不合时期的作物/题字/结构，由建模任务书剔除。

## 本轮实施与放置约束

- 三张概念和完整提示词：`briefs/rome/life-20261025/`。一资产一工人，一份任务书。最多两个Blender进程，每个2线程；CPU预览避免旧的并行GPU卡死。
- 街边交易组最多8、烘焙间最多4，按牛市、苏布拉、卡里奈、原始学院附近分散。只在现有灰石/泥路的拓宽处择址，不占用大理石礼仪广场、建筑、私家庭院、水域或主干道。
- 检查完整外轮廓与每米采样，不只检查原点。地面最大落差0.18m，抬高只有0.06m；不能容纳就放弃此位置，不垫高盒子。
- 主干道额外保留1.5m边距，商摊/工作间前至少1.5m清晰接近空间；同类群组之间至少24m，并避开已有小物。
- 庭院角落只使用已验证完整的旧式庭院宅；整组必须位于院心保护多边形内，而且避开已有柱列、柱廊瓦顶、水池和通路。选中的四院采用完整园景组合：休憩角位于柱廊内侧开敞面，较小水池安排在另一侧，中间留出接近空间；所有8座完整宅翼保留。它是坐凳/希腊柱子/花木等园景设施，没有新增居住房间。
- 多次布置走现有GLB实例化，每种材质一组实例；不逐个加灯、动画或大贴图。打包仍使用现有quantize+gzip。
- 当前只在本地分支制作；保存源脚本、GLB、四视图、可续作blend、审图记录与现场截图。任务结束时补实际指标和偏差，未过审不能写成完成。

三者都满足硬性面数与占地限制；都超过原始150KB软目标，但压缩后合计161.7KiB，实际Rome打包增加约0.22MB（含base64）。本轮未测试不同硬件帧率；实例化只避免副本数量增加独立绘制批次，不代表零渲染开销。

- 市集第一轮：石头柜台过于像现代设施、货箱把商贩通道压至约0.6m、整片棚布遮住所有商品。修改为木板台、箱在台下、后退棚布，通道至少约1.4m（保守计入台边）。俯视可看到四组商品。
- 烘焙第一轮：拱口转了90°、穹壳开口锯齿、瓦顶断裂、磨石轮廓错误、碗悬在桌外。第二轮改善后，主审又发现后屋梁没有落地支撑；第三轮补后柱。炉口为实际敞口和衬里，约0.8m宽、0.715m高，短喉深0.6m。没有发光火焰。
- 庭院第一轮：柱顶与梁底相差7cm，卷涡过大且位置太低，盆栽像亮斑圆球。第二轮让梁坐实、卷涡附着柱头、缩短肖像颈部、改为不对称叶团。
- 现场审图：两处相机起初被房屋遮挡，已移到场所上方；院内新棚曾与旧柱列相撞，已把柱列和瓦顶的真实内边界纳入放置与断言，并调整选中四院的池/棚布局。不能只用“位于院心多边形内”就判定不碰撞。

分支 `codex/roman-street-life`。模型由3个Luna工人制作，市集2轮、烘焙3轮、庭院2轮；均已关闭。CPU渲染最大2线程/实例。原始参考未写入这些产物。

可复现验证：`node tools/build.mjs --test && node tools/check.mjs && node tools/test/street-life-city.mjs`。报告和现场图存于 `shots/street-life-20261025/`，四视图和可续作blend位于对应 `renders/rome_*/`。这批是静态场所资产，人物动作和经营动画仍未制作。

最终实城验收（密度1）：8组成对市集、4处烘焙间、4处休憩角；旧庭院宅仍为阿文提诺4座/学院4座，院面支撑与屋檐关系通过；导出模型尺寸通过。检测到的占路、侵入其他占地、院内柱列/瓦顶/水池碰撞为0，浏览器/GLSL错误为0。此结果限定于这批资产的准入与上述断言，不扩展为全城所有历史模型零碰撞。休憩角浅铺地抬8cm、底部埋入院台，避免与原草地/小路共面产生条纹。
