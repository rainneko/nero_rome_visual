# 网页渲染性能（2026-10-24）

分支：codex/web-render-performance。保留本轮之前所有未提交的植被与文档工作。

## 第一批改动

默认均衡：渲染像素比例最高 1.25、2048 阴影、桌面 2× MSAA。轻晶格保持开启，Kuwahara 平涂在半宽半高目标上执行，原图合成与晶格输出保留主画面分辨率。采样间距仍使用原图像素尺寸，避免把笔触范围扩大两倍。

控制面板 → 画面滤镜 → 画质：

| 档位 | 最大像素比例 | 阴影尺寸 | 桌面 MSAA | 轻晶格平涂分辨率 |
|---|---:|---:|---:|---|
| 流畅 | 1 | 1024 | 0 | 半宽半高 |
| 均衡（默认） | 1.25 | 2048 | 2 | 半宽半高 |
| 精细 | 1.5 | 4096 | 4 | 原分辨率 |

触屏、小窗口保持无 MSAA；画质偏好本地保存。完整晶格和画意滤镜仍用原分辨率。没有修改模型密度、建筑布局或植被种类。

## 验证方法

`tools/test/performance.mjs` 对比 dist/perf-before.html（改动前页面快照）与 dist/test.html，**均不带 ?test**，1000×720 CSS 像素、DPR 1.5。等待模型完成，固定广场视角，采样帧间隔并截图。使用 SwiftShader 软件渲染，因此结果只用于同环境对比，不代表用户硬件帧率。截图和结果在 shots/perf-*.png、shots/performance.json。

基线文件是本地生成文件，不随 Git 提交；再次建立基线应在修改前运行 `node tools/build.mjs --test` 并复制 dist/test.html 到 dist/perf-before.html。
