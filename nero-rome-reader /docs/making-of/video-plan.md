# 视频方案：Building Rome in One Day

> 副标题：Rome wasn't built in one day — but you can build your city in one day.
> 时长目标：主片 8–10 分钟（B 站 / YouTube），另剪 60 秒竖版（抖音 / Shorts / 小红书）。

## 一句话卖点
**一本 43 万字的小说，变成一座会随情节生长的 3D 罗马。** 第一天就能建出整座城，后面两周只是在"装修"。
每一步花了多少 token，全部公开。

## 需要补拍的素材
1. **真实浏览器录屏**，1080p 或 4K，开轻晶格，带音乐。由作者录，无头浏览器录不了音频和流畅帧：
   * 滚动阅读触发状态变化。
   * 点地名飞行。
   * 昼夜滑块。
   * 夜景。
2. 第一天版本 `novel2city/examples/rome-day1.html` 的同机位录屏，用于对比。
3. Blender 建模过程的延时，可以用 `renders/<asset>/` 的多轮渲染拼成翻页动画。
4. 多 agent 工作的界面录屏：主控派活、Haiku 交报告、拼图审图。
5. token 条形图动画，数据见 `token-ledger.md` 和 `data/*.csv`。

## 60 秒竖版
* 0–5 秒："一天建一座罗马？"第一天鸟瞰。
* 5–20 秒：小说滚动 → 城市变化。
* 20–40 秒：快剪 4 个资产的"第一版 → 最终版"。
* 40–55 秒：数据卡"11 亿 token / 44 个 AI agent / 道路最贵"。
* 55–60 秒：GitHub。
