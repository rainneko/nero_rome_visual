# 镜头设计：大竞技场热气球（C 槽第一条）

作者的意见（2026-10-26）：运镜不够震撼；能不能环绕大竞技场一圈；看台上没有人群；要有参考图那样的光影和气势。
这份是视频组的方案和给代码组的功能清单。生图部分单独写在 `briefs/video/c1-balloon-images.md`。

## 一　时间：午后斜阳，不是黄昏（作者 2026-10-26 定）

小说没写几点，但 505 行是"停在蓝天里"。黄昏的天是橙红的，和原文冲突。
所以用**午后斜阳**：太阳低、偏西，暖光斜扫看台，影子拉长，天还是蓝的。这样能拿到参考图那种光，也守住原文。
三维镜头用 `tod` 0.64、`sunAz` 250；生图也照这个光（`briefs/video/c1-balloon-images.md` 第二节）。

## 二　节拍（约 16 秒）

| 时间 | 画面 | 声音、字幕 |
|---|---|---|
| 0–2.5 秒 | **S1 生图**：包厢阴影里的视角，尼禄背影挥紫手帕，场中央的球鼓到一半。前后景分层，慢推 | 人群嘈杂；不出字 |
| 2.5–9 秒 | **三维**：绕大竞技场转一圈（`x-C1b-balloon-orbit`），球从场中升起，越过看台；中间插 1.5 秒 **S2 生图**（从看台仰看） | 长号两声；字幕：球升起来。十米，二十米，五十米，越过看台顶上，停在蓝天里。 |
| 9–12 秒 | **S3 生图**或三维大远景：球停在蓝天里，花瓣慢慢落 | **全部静音**，不加字 |
| 12–16 秒 | **S4 生图**：十五万人一起喊，前后景视差；最后切回三维航拍 | 人声和号声一起进来 |

三维和生图的分工：三维负责"这座城真的在那里"，也就是全景、环绕和尺度；生图负责三维拍不了的近景和情绪。

## 三　现在三维能做到的

`x-C1b-balloon-orbit`：20 秒，绕球转 360°，午后光（`tod` 0.64，太阳方位 250°），球在 5–12 秒升起。
录制脚本这次新加了 `sunAz`：阅读器里的太阳一直在东北偏东，所以午后镜头要单独把太阳设到西边。

原来的差距和现在的状态（2026-10-26，视频组做的，改动在 funny-golick 分支）：
1. 看台空着 → 已坐满约 4.6 万人，能站起来欢呼（`fx.crowdCheer`）。
2. 天是灰白的 → 录制脚本加了 `sky`，按镜头把天调蓝，阅读器本身不变。
3. 球是低面数的，没有炉火 → 球皮改成 36 段的圆滑轮廓；加了双层铜环炉、火焰和吊篮里的两个白袍学徒；场中央有木架，球从瘪的一条慢慢鼓起来（`fx.balloonFill`、`fx.rig`）。
4. 球原来就停在石堤正上方 → 升空点移到皇家包厢前的赛道上（离中轴 22 m）。
5. 没有花瓣、尘埃和光柱 → 花瓣一片约 10 cm，航拍时不到一个像素，三维里做了也看不见，改由生图近景和剪辑时叠加的花瓣层来做；光柱还在代码组的单子上。

加强版两条：
- `x-C1h-launch`：20 秒绕场 240°。0–5 秒球在木架上鼓起来，6–11 秒升空，11–14 秒静止，14 秒起看台欢呼。
- `x-C1h-crane`：16 秒，机位在皇家包厢旁的看台上，坐着的人的视线高度。先看球在两根桅杆之间鼓满，再跟着球升起，摇到仰看蓝天。

## 四　请代码组加的功能

要求：所有效果都放在可开关的图层或参数里，不显示的时候不花性能；随机都用固定种子，同一时间同一帧（录制脚本用虚拟时钟逐帧拍，要能重拍出一模一样的画面）。
做完之后告诉视频组参数名，录制脚本会加对应的镜头字段。

| 优先级 | 功能 | 验收 |
|---|---|---|
| P1 | **大竞技场看台人群**：~~铺人~~ 已由视频组做好（2026-10-26）：图层 `circusCrowd`（`src/scenes/rome/layers.js`），用罗马广场人群的同一个小人模型，按看台斜面（离中轴 42 m 处高 3 m，77 m 处高 24 m）坐满，约 4.6 万人，18 % 穿四队颜色；只在状态 0 显示；画质"精细"全画，"平衡"画 60 %，"流畅"画 35 %，帧时间分别多 8 %、5 %、2 %。欢呼也已做好：`fx.crowdCheer`（0 坐着，1 全体站起来，各自按自己的节奏跳）。挥布条还没有 | 欢呼从 0 推到 1 时，整个看台有一波起伏 |
| P2（不做三维） | **玫瑰花瓣**：从吊篮往下撒，飘、翻、慢慢落，被斜阳照亮；参数是开始时间。顺带加空气里的尘埃微粒 | 环绕镜头里，球下方有一道看得见的花瓣流 |
| P3（视频组已做） | **热气球升级**：球皮更圆（多些分段，略有光泽）；双层铜环炉，有一点橙色火光（加一盏小点光源）；吊篮里两个白袍小人；加一个"鼓起"参数（0 是瘪的布堆在场中央，1 是满的）；升空时缆绳松开 | 近景不再看出棱角；鼓起 0→1 是连续的 |
| P4 | **光柱和更亮的泛光**：太阳方向的屏幕空间光柱（three r147 自带 GodRaysShader 可以参考），强度可调；现在泛光是 0.06，加一个参数让镜头里能调高 | 逆光机位能看到从看台缝里射出的光 |
| P5 | **"蓝天"**：晴天的天顶颜色加深，或者加一个 `clearDeep` 天气，让午后的天是饱和的蓝，不是灰白 | 截图里天空上半部明显是蓝的 |
| P6 | **太阳随时间走**：上午在东、中午在南、下午在西（现在固定在 68°）。录制脚本已经能按镜头单独设，这条是给阅读器本身用的 | 拖动昼夜滑块时影子方向会转 |

P1–P3 是这个镜头必须的，P4、P5 是加分，P6 不急。
代码组现在的重点是道路、空地和克劳狄神庙，这些可以排在它们后面，但最好在录总览之前做完：总览也要拍大竞技场。

## 五　后期能做的

不用等代码组，剪辑时就能加：
- 调色：暖高光、偏青的暗部。
- 泛光、轻微的镜头光晕、胶片颗粒和暗角。
- 生图的视差推镜：前后景分层后，前景移动得比背景快。
- 声音：人群嘈杂、长号、静音三秒，然后人声爆发。

光柱和花瓣也能在后期叠素材，但三维里没有遮挡关系，会显得假，所以还是请代码组做。
