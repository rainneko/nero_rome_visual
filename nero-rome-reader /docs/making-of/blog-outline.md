# 技术博客提纲：Building Rome in One Day

> 先留骨架和论据，正文以后写。所有数字出自 `token-ledger.md`（实测）或标明"作者估计"。

## 标题候选
1. Building Rome in One Day — a novel, 44 AI agents, and 1.1 billion tokens
2. 把小说建成会随情节变化的城市：第一天建城，两周装修
3. 1.1 B tokens later: what actually costs money when AI agents build a 3D city

## 1. 开场：为什么是一本小说
* 《尼禄重工纪元》，43 万字的历史基建文。读者需要"看见"城市，而且城市要跟着情节变：
  * 公元 54 年的罗马 → 高炉、学园、铁轨陆续出现；
  * 尼禄长廊、克劳狄神庙工地按章节出现。
* 代码：https://github.com/rainneko/nero_rome_visual
* Skill：novel2city。

## 2. 第一天：结构对了，城就有了（作者估计 1–2 个 5 小时额度）
* 用了哪些 skill 和思路：
  * novel2city 流程：设定圣经 → 地点表 / 状态表 → 史料 → 参考图。
  * 开源城建游戏和 athenaion 的程序化城市做法。
  * 无头截图验收。
* 做了什么：
  1. 调研城市模型。
  2. 选史料（Platner、Forma Urbis）。
  3. 从参考鸟瞰图量街区密度。
  4. 生成低/高密度民居、神殿、皇宫。
  5. 做成单文件阅读器 + 时代状态。
* 产出：`novel2city/examples/rome-day1.html`（173 KB，浏览器直接打开）。
* 论点：**第一天最值钱的是"对的骨架"**：1 米尺度、地标预留、时代过滤、状态系统。后面所有精修都建立在它上面。

## 3. 之后两周：token 都花在资源配置上（作者估计约 2 个周额度）
* 总表：Opus 302 M / Sonnet 384 M / Haiku 432 M，共 1.12 B，其中约 94 % 是缓存读取。
* 按阶段：安齐奥 184 M、罗马资产 372 M、帕拉蒂尼 + 街道 + 立面 339 M、后续修改 149 M、试验 66 M。
* 每个资产：中位数约 11 M；一次过 2–3 M；续用 + 多轮 25–36 M。
* 道路是单项最贵（约 1.22 亿），为什么：
  * 作者对第一版极不满意；
  * 规则从"路网"改成"在密集建筑区外自然生成"；
  * 三个等级；陡坡变阶梯；
  * 后来还修了"电车轨"车辙。
* 图：条形图（阶段）、散点（资产：轮数 vs token）、折线（主控上下文长度随时间）。

## 4. 多 agent 分工
* 作者当导演。
* Opus 主控：计划、任务书、审图。
* Sonnet 集成：跨文件代码、地形、着色器、自截图。
* Haiku 工人：Blender 无头，一次一件。
* Gemini 当史学顾问：一半有用（夜景、阿文提诺），一半要核实（编造的清单、"GIS 数据"）。
* 交接文件：`briefs/*.md`、`docs/TODO.md`、阶段交接 `phase*.md`。

## 5. 分析：哪些 skill 有用，哪些不匹配
**有用：**
* Blender 无头 + Haiku 工人 + 共享积木库 + 任务书。配方写清楚时一次过，2–3 M 一件。
* novel2city 的"不许出现清单"和参考图打分。罗马的时代穿帮几乎都在这里被拦住。
* 城建游戏、athenaion 的程序化思路。第一天就铺出几千栋民居（现在约 2 万地块）。
* 无头截图 + 拼图审图 + 像素探针（数字验收）。
* Sonnet 当集成工程师，前提是每阶段新开。

**不匹配或不值：**
* img2threejs：单物体照片重建流程，门槛不认街景参考图。35 M 只到第一阶段。
* 顶点 AO 烘焙：31 M，效果小，文件大 1.7 倍。
* 续用长上下文工人：每次调用贵 2.6–5 倍。
* "再像参考一点"式的含糊验收：3–5 轮。
* 照片投影贴图：参考多是游戏截图，等于搬运别人的美术。

## 6. 可复用的规则（写进 skill 了）
1. 修改轮一律新开工人，10 行交接。
2. 两轮不过就换配方或数字验收。
3. 先查几何（悬浮、未连接）再渲染。
4. 审图用"参考图 | 渲染图"并排拼图。
5. 集成工程师按阶段重开，15 行交接。
6. 试验先在 1 个模型上量化。

## 7. 局限与诚实
* 实测只覆盖 10-21 至 10-23；第一天和 10-19 至 10-21 的迭代没有记录。
* token 不等于钱：缓存读取便宜得多，模型单价也不同；文中不换算美元。
* 实时程序化渲染离游戏截图的手绘质感还很远。
