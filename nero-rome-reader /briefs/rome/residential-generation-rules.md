# 普适住宅生成规则（替代逐栋修补）

本轮的 X 是生成失败类别，不是一份按坐标删除的清单。规则入口在 `src/world/residential-policy.js`，普通地块、中心补房、零散住宅及随机公寓放置都受准入约束。模板公共建筑、神殿和经过规划的宫殿资产按各自用途放置。

1. **有用途的空间不能当剩余空地。** 所有生成院落均登记保护范围；旧贵族宅院登记整个宅地，花园另作标记。皇宫山上的院落、台基与台地属于规划区，普通随机补房没有默认准入权；已有的宫殿、客舍、官署和规划宅邸保留。
2. **实心住宅有尺寸上限。** 无院实体长边≤22m、短边≤16m、面积≤260㎡。超限地块继续切分，最多6级；无法符合时拒绝。面积>280㎡或边长>24m的元老宅地必须有净宽≥5m、面积≥35㎡的实际庭院，否则由地块层继续拆小，禁止退化成长条实心楼。
3. **大宅是建筑组。** 宅翼屋顶按≤14m独立分段；段间可变化屋脊高度、hip/gable端部和瓦色。三层为主、四层为辅，翼间最多差一层。这里是本项目的艺术与尺度约束，不宣称罗马考古存在上述精确数值法规。
4. **庭院必须有支撑和竖向关系。** 庭院地坪高于范围内最高地形，并生成实体支撑侧壁。旧宅邻翼最低屋檐至少高于花园3.9m，给3.4m高柱廊留余量；新宅最低翼檐口至少高于庭院2m，实际柱廊高度还须低于檐口。原最低住宅基底规则保留，不能把整个街区抬成统一高台。
5. **门窗与廊口只能有一个所有者。** 几何 gallery 负责拱口，墙面 shader 不再重复画住宅假拱；附加窗框避开廊层，窗几何背面使用无窗面，避免二次叠画。
6. **走廊可读。** 环廊宽0.8–1.1m，后墙32cm，有地面、顶面、内墙、木门。浅色非发光材质、适度AO保留明暗，转角通透；不靠新增大量灯光补救。正常商铺入口与小窗仍可较暗，基础上的盲拱不等于开放走廊。
7. **道路与坡度是硬约束。** 沿用最终屋檐轮廓碰撞与倒数第二层埋地阈值。建筑尺寸失败、道路冲突、侵入已登记庭院均须拆分或拒绝，不得强行降级成 X 类楼体。

验证分为生产几何单元检查和整城浏览器检查。前者覆盖50m长地块拆分、花园拒建、实体院基、最低邻翼高度、真实后墙射线、走廊转角与天空可见性；后者检查全城保护空间侵入、实心尺度超限、院落竖向关系和道路交集，并保存实际截图。

## 本轮验收结果

- 单元：50×20m无院地块拆成4块合规小地块；花园内补房被拒绝，外侧小房可生成；实体花园基座与最低邻翼高度通过。
- 拱廊：生产几何射线、转角/地面/天空可见性通过；实际网页渲染能看到后墙与木门。专用材质不发光，也没有新增灯。
- 整城：24,451条地块住宅记录，1,255处保护范围（含248处旧贵族花园与248处宅地）。后续侵入、皇宫区随机补房、实心尺度超限、庭院竖向关系失败、主街交集均为0。另有1,668条实际gallery记录。记录数不是住户数或全部静态建筑数。
- 修改采用两名Luna各两轮，均已结束。主审检查了实际旧庭院、元老街区与帕拉蒂尼山截图。
