# 剧情资产施工阶段 · 首批建模任务

来源：同事的 `construction-stages.md`，16 张资产卡、46 张完工参考图。完整任务书只读副本与所有改绘图片保存在被 Git 忽略的 `renders/construction/`。

本批交付对象：南岸高炉组 `furnaceA`、平炉／化工组 `chem`。其余 14 张卡继续登记在该目录的 `manifest.json`；克劳狄神庙由另一会话负责，避免重复或覆盖。

## 依据与取舍

- 小说原文是情节依据，现有 Three.js 图层是尺寸与位置依据；AI 改绘只表达施工工艺，不能反向改变场地规划。
- 第 19 章原文写了“三座高耸的红砖烟囱”，没有直接规定三座高炉。此次保留当前场景的三套炉体，标为既有视觉设计。
- 第 29 章搬迁的是洗矿池、铅室、焦化设施，不能把当前高炉迁移的视觉错误当作新任务的剧情依据。该修正另行集成。
- 圣辉大殿应是木骨架承重、外覆木模浇筑混凝土的顺序；不能套用石砌哥特教堂施工。尚未建模。
- 小说有推车等技术设定；本批施工工具仍按任务书约束，采用木脚手架、绳索、木滑轮，不添加现代设备。

## 先图后模的审图结论

两张原始完工图分别生成一张四格设计图。高炉图的 K0→K3 过程可参考。化工图把平炉厂房挪到中央、显著放大，**该布局被否决**；模型严格采用 `src/scenes/rome/layers.js` 的 `openHearth`、`kiln` 等坐标尺寸。

二维图生图不能保证相邻帧的背景像素一致。正式关键帧由同一份城市场景、同一固定机位和时刻渲染各个阶段模型，不以裁剪设计图冒充动画帧。

## 坐标与阶段接口

全部 GLB 共用工业区原点，不按各自包围盒居中。

- 原点：`[-1190, W0.gy(-1190,2760), 2760]`，网页绕 Y 轴 `-50°`。
- Blender `[X,Y,Z]` 对应现有局部 `[x,-z,y]`，单位米。
- 文件：`assets/models/construction/<id>/K0.glb` 至 `K3.glb`。
- `K0` 测量与材料堆；`K1` 基础及低墙；`K2` 主体、木脚手架、拱架；`K3` 全高、半屋面、冷烟囱。
- `K4` 直接使用网页原有完工图层；`K5` 加回该图层原有烟雾。没有悄悄替换完成模型。
- 阶段对象名建议 `<id>@K<n>`；只能显示一个阶段，地面高度和 footprint 不变。不能用整体 Y 缩放或从地下滑出代替施工。

## 验收与交接

运行模型脚本后，执行 `npm run build:test`，再执行 `node tools/test/construction-stages.mjs`。

工具在 `renders/construction/review.html` 创建独立审阅页，导出 1920×1080 的 K0–K5 三分之四视角及俯视图，记录 `audit.json`：机位一致、场地范围、三角形预算、坐标及阶段互斥。Blender 源文件、四机位模型预览和数量报告由各工人输出在 `<id>/model/`。

本批先完成资产与审阅场景。现有阅读器 `rise` 动画和故事年代不会在该任务里被无依据改写。主阅读器接入时需明确每个 K 阶段的章节触发条件；两阶段切换建议短交叉淡入，避免现有 K4 与新材质瞬间跳变。

输出为 8 个 GLB、8 个可续作 Blender 场景、两组各四机位 K2 预览及 K3 加拍，另有 32 张城市关键帧/工艺近景；所有最终场景 PNG 为 1920×1080。K0–K5 的斜视与俯视共24张，K2/K3的两种近景共8张。图片画廊为 `renders/construction/index.html`，三维固定机位切换为 `review.html`。

8 个 GLB 的量化审阅载荷共 3,918,472 字节，保留原始模型供后续打磨。审阅页对新材质调用现有 `romeMat`（砖、石、木的别名和色值适配见工具的 `stageMaterial`），保持城市的大气、图案与轻晶格处理一致；直接使用 GLTF 默认材质会明显偏红。

`npm run check` 通过。`audit.json` 的32帧验证无浏览器错误，原图层 rise 参数26/20保留，所有新阶段在工业区原有范围内。另做16次背景像素比较：高炉场地保护框外差异为0；化工框外约130–147万像素中最多13像素差异超过4/255，最大6/255，属于后期处理的极小全局影响。没有宣称图生图做到逐像素锁定。可用 `python3 tools/test/construction-background.py`（Pillow/NumPy）复核。

**尚未交付的部分：** 高炉K0保留完工堤岸，只倒推炉组；河滩填土与堤岸施工前置模型未做。其余14张卡未完成；主阅读器的章节阶段触发和 rise 动画替换未接入。审阅页保持邻近建筑固定是为了比较单项资产，不能当作同一小说年代的城市实况。
