# 民居拱洞与拱廊（2026-10-24）

用户目标：底层、二层和顶层可有拱廊；避免每层都是巨大黑色开口。结构应为外层拱廊—走廊—内侧后墙。

## 已实现

- `src/core/materials.js`：住宅 bArc 大拱口只保留底层、顶层及 seed 选择的二层（42% 的 bArc 住宅），公共建筑的石材拱廊保持原楼层规则。普通住宅“扩大拱窗”的条件从约30%降至18%，且只允许二层或顶层；不额外消耗随机数、不改变建筑选址。
- 远景开口使用解析视差盒：视线命中走廊侧墙、地面、顶棚或封闭后墙。后墙暖灰泥色，少量有关闭的窄木门；降低额外 AO，不以发光材质照亮内部。普通小窗、商铺原有逻辑保留。
- `src/world/lots.js`：真实顶层拱廊保留约2.4m深度，原来的近黑背板换为灰泥后墙、侧墙、浅色顶棚和铺石地面，补一扇关闭木门。
- 概率是视觉设计规则，不是考古统计。这里改的是程序化民居规则，没有批量重建GLB资产。

## 验证与样件

- `tools/test/arcades.mjs`：用项目真实着色器、几何生成器构建3栋对照住宅，读取 Git HEAD 作为修改前基线。截取普通画面、轻晶格两组。`shots/arcades/` 为结果；不是完整城市性能测试。
- `tools/models/rome/gallery_study.py`：Luna 建模，经负责人审图修正后，用本机 Blender 5.2.3 后台渲染。三开间、真实拱洞、封闭后墙与端墙、窄木门、地板与顶棚，864三角面。`renders/gallery-study/` 包含 blend、glb、three.png、street.png。
- 样件用于结构审查，尚未替换城市中的现有GLB。
- 已安装 Blender MCP 插件，但本轮检测127.0.0.1:9876连接被拒绝；本轮使用 Blender 后台Python，无须修改用户当前UI场景。

## 第二轮：真实转角与图二长廊（2026-10-24）

第一轮没有全面解决转角：部分顶层仍为视差开口；已有真实拱廊也只在正面开洞、端墙封闭。Blender样件不等于已接入民居。

本轮用 `houseGalleryPlan / houseShell / houseGallery / houseRectWalls` 统一地块民居与补空隙民居：

- 连续顶层拱廊使用真实挖空的四面拱墙，后面为连续环形走廊，内侧是带木门的实体房间墙。转角没有隔断；有地板与向下可见的顶棚。
- 外墙/后墙厚0.32m，走廊净宽约1.0–1.4m；三连拱局部走廊净宽约1.34m。0.3m适合作为墙厚，不是通行宽度。
- 大立面（正面宽至少14.5m，约5开间）且至少5层的民居，可按seed约38%的设计概率，在第三或第四层开三连拱；排除倒数第二层，保留两侧完整墙段。
- 真实四面顶廊的选择覆盖 loggia/loggiaA、bLog/bArc 的合适四边形住宅；小窗和底层店铺仍为轻量立面表现。未声称全城全部开口均为实体。

图二对应 `monuments.js` 中从(252,232)到(620,-28)的旧宫苑连接区占位，不是经核实的具名公共建筑。`eastPalaceGallery` 将其改为中部房间、两侧净宽约1.72m真实廊道的双层建筑，含楼板、顶棚、后墙和瓦顶。沿原路线细分约20m的结构段，共享端点高度；陡段两层都加浅踏步。基础按横断面地形采样，不再把相邻整段高差塞进3m长楼梯里。功能按宫苑外围办事/服务用房设计，不标作已证实史实。

验收：`tools/test/gallery-structure.mjs` 对真实几何作射线检查：拱廊转角贯通、从中部开口向内能命中1.86m处实体后墙；中层三连拱与补空隙路径生效；平地和斜坡公共廊道接头楼板高差为零，斜坡踏步高不超过0.18m。普通和轻晶格截图位于 `shots/gallery-structure/`。`tools/test/gallery-city.mjs` 启动真实城市并静态截图，是功能验收，不是帧率测试。
