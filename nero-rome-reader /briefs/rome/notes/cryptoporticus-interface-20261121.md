### 1.3 两头和门

- 西端 P0 是一块 5.8 m 宽的封墙，在提比略宫模型 x 66.4，**没有门洞**。
- 东端 P4 是一块斜的封墙（垂直于 P3→P4，和东宫西墙成 26.6°），两角在东宫模型 (−62.0, 37.0) 和 (−64.6, 31.8)，**没有门洞**。

  - P1 的门：山丘 (−69, −61.57)，场景 (71.0, 212.2)
  - P3 的门：山丘 (2, −98.57)，场景 (151.0, 215.6)
- 中间有一个**穿廊拱**：`PAL_ARCHES=[[2,−26.5]]`（`pal:424`），P2→P3 段在山丘 lx −26.5（场景 (127.8, 198.8)）处是 6.4 m 长的开敞拱廊，一条巷子在 deck 高度从暗廊底下穿过去。要做成能走的暗廊，这里会被一条横巷切断【推】。

### 1.4 采光

- 墙面着色器画的小拱窗（`sty:1, nSt:3, gH 2.5, sH 2.6, floorY 49.02`，`pal:429`）：第一层窗在 49.02–51.52（埋在铺地以下，看不见），第二层在 51.52–54.12，是贴图不是窗洞。`lit:0`，夜里不亮。
- 里面没有任何光源，因为里面没有空间。
- 标签说“光线从拱顶的窗洞透进来”标着【史】（`pal:450`）；东宫会话（B8 节）说查不到出处，提比略宫 18.5 节也写了。这句应改【设】或删。

### 1.5 第一人称能不能进

- 第一人称行走（`src/ui/fp.js:1–17`，main 上有）是从上往下拍高度图，脚下只认“头顶以下最高的那一层”，墙从斜拍图里读出来。暗廊四面都是墙，没有开口 → **进不去**【码】。即使进去，里面的地面是 deck 51.52，头顶 2.55 m 处是平板。
- 屋顶步道 54.54：从 deck 上去差 3 m，没有楼梯；从提比略宫台基顶 54.8 走过去只差 0.26（`STEP 0.5` 以内），西端 GLB 上还有一块顶面 54.35–54.71 的东西伸到模型 x ≈ 66.8（见 3.1），所以**也许**能从提比略宫东侧走上步道。没有实跑验证【推】。

## 3. 缺口

踏步按 0.17 踢 / 0.30 踏算。“deck 方案”= 暗廊地面就用现有 51.52；“49.02 方案”= 两个会话都在用的名义下层地面（要把暗廊整个往下挖 2.5 m，墙脚也得重做）。

### 3.1 西端：U5 ↔ 暗廊

- 平面距离：门洞中心线 x 65 → 暗廊西端封墙 x 66.4，**1.4 m**；从外皮 64.7 算 **1.7 m**【码+测】。横向对得正：暗廊中轴 y 34.7 = 门洞中心 y 34.7。现有一层门 doorC 偏北 0.6 m（y 35.3）。
- 高差：
  - deck 方案：暗廊 51.52 比 U5 门槛 50.8 **高 0.72 m** → 5 级（每级 0.144）或 4 级 0.17 + 0.04 收口，踏面合计 1.2–1.5 m。正好塞进 1.7 m 缺口，或者放在暗廊西端 3 m 的短段里。
  - 49.02 方案：暗廊比门槛**低 1.78 m** → 11 级，跑长 3.3 m。提比略宫写的“九级、放在头 3 m 里”是每级 0.20 / 0.33，按 0.17 的坡度放不下 3 m。
  - 一层：步道 54.54 比 doorC 门槛 54.8 低 0.26 → 2 级，0.6 m。
- 路上有什么【测】：
  - 天然地形 49.2–49.44（x 64.6–66.4）。**U5 门槛 50.8 比外面的地面还高 1.4–1.6 m**：这个“地下门”出了墙其实是露在地面以上的，接过去的那 1.4 m 要么做成实心垫起来，要么让地形补上。
  - 提比略宫 GLB（main 上的版本）：台基边在模型 x ≈ 65.1，墙外是 z −7 的第二层台地（顶 47.8，被地形埋着），一直到 x ≈ 71.1，再往外掉到 38.8 以下。还有一块顶在 54.35–54.71、伸到 x ≈ 66.8 的东西，从 y0 50.8 到 54 的水平射线都打在 x 66.8【测】，没认出是什么（像门前平台或扶壁）。它和暗廊西端的拐角块（x 66.5 起）重叠约 0.3 m。下口通道顶如果在 50.8 + 2.6 = 53.4，就从它下面过，不碰【推】。
  - 提比略宫自己的问题（18.7 节已写）：台基在模型里是实心填块，U5 前室在填块里面。

### 3.2 东端：暗廊 ↔ B13

- 平面距离：暗廊东端封墙中心 P4 (−63.3, 34.4) → 东宫西墙 x −56，沿模型 x **7.3 m**；沿 P3→P4 方向量是 8.2 m；离墙最近的封墙角 (−62.0, 37.0) 是 **6.0 m**【码】。横向：暗廊轴 y 34.4，doorW y 34.5，差 0.1。方向：暗廊最后一段方位 146.6°，门轴 120°，**要拐 26.6°**。
- 高差：
  - deck 方案：B13 52.2 比 51.52 **高 0.68 m** → 4 级，1.2 m。
  - 49.02 方案：高 3.18 m → 19 级，跑长 5.7 m（东宫写的“18 级在 7.3 m 里”是每级 0.177 / 0.41，能放下，但要连着一段平台和 26.6° 的拐弯一起算）。

  - 东宫 GLB 在暗廊**东端的里面**就已经有东西：lx 6–11（东宫模型 x −67.3…−62.3）是一块顶面 51.70–51.83 的低台，比 deck 高 0.2–0.3，暗廊最后一段的墙（51.02–54.12）立在它里面；lx 5.3–6.5 有一个面高到 53.18。**暗廊最后 5 m 和东宫 GLB 已经互相穿插**。

### 3.3 中段（两种方案共同）

- 暗廊里外唯一的地面是 deck 51.52；做成能走的室内，要补：开两头的门洞、内墙面（现在单面朝外）、地面、拱顶或至少顶板底面、灯光，以及 lx −26.5 那个穿廊拱怎么处理（一条巷子在同一高度横穿）。
- 走廊本身挨着鞍部的办公楼（main 上的 `PAL_BL`）：d 楼 (−46.5, −81.5) 的西墙 lx −65 离 P1→P2 段外皮 −66.1 只有 1.1 m；北墙 lz −96 离 P2→P3 段外皮 −98.6 是 2.6 m【码】。往下挖（49.02 方案）会碰这两栋楼的基础【推】。

### 3.4 一个不用挖的折中【推】

两座宫的地下层差 1.4 m（提比略 50.8，东宫 52.2），暗廊长 120 m。如果暗廊地面从西端 50.8 缓坡升到东端 52.2（坡度约 1.2%，看不出来），两头都不用踏步，中段的地面始终在 deck 51.52 上下 0.7 m 以内，墙脚只要往下补 0.2 m。净高按顶板底 54.07 算是 2.0–3.3 m，西头偏矮；要像样的筒拱，顶板和屋顶步道得一起抬，这就要改 `palatine.js`。

## 4. 两份规划之间、以及和代码对不上的地方

1. **“暗廊下层地面 49.02”两边都在用，但它不是几何**，只是墙面着色参数。代码里没有下层；暗廊整体是立在 deck 51.52 上的一个实心盒子，屋顶上一层有柱子的步道（54.54）。东宫 B8 节已注意到“下层没有地面”，提比略宫 18.9 节的表仍把 49.02 写成“下层地面”。
2. **两边算踏步用的是同一个 49.02，却得出两套不同的坡度**：西边 9 级 1.8 m 放 3 m（每级 0.20），东边 18 级 3.18 m 放 7.3 m（每级 0.177）。按 0.17/0.30 西边放不下。改成 deck 方案后两头都只要 4–5 级。
3. **两座宫的地下层不在一个高度**：提比略 B1 −4.0 → 50.8；东宫 B1 −4.5 → 52.2，差 1.4 m。东宫平面 JSON 的 `floor_heights.B1` 是 4.0，规划文写净高 3.6 + 拱和楼板 0.9 = 4.5，不一致。
4. **暗廊两头都没接上宫**：西头离提比略宫东墙 1.4 m（提比略宫写“贴宫东墙”）；东头离东宫西墙 7.3 m，还斜 26.6°，且最后 5 m 已经插进东宫 GLB 的低台里。
5. **“地下”门其实在地面以上**：U5 门槛 50.8 比墙外地形 49.2–49.4 高；B13 地面 52.2 比东宫西侧地形 48.6–50.2 高，只是被 GLB 门前平台的台身包着。提比略宫会话量到的“墙外地面比台基顶低 4.3–5.0”是天然地形，那里实际能站的是 deck 51.52（它的射线打不到合并网格，所以没看到 deck）。
6. **B13 的位置和东宫自己的约束冲突**：B13 西边贴着外墙线 x −56，但 B8 节的硬约束 1 要求新房间离外墙面至少 2 m；而暗廊恰好要从这面墙进来。B13 西墙的“四个高窗”有一段被 56.7 的门前平台挡住。
7. **U5 的采光写“靠暗廊自己的小拱窗”**：U5 在提比略宫台基里面，暗廊的窗（而且只是贴图）照不到它。
8. **长度**：标签和提比略宫平面备注写约 130 m，代码中心线 119.9 m。
9. **【史】标注**：标签里“光线从拱顶的窗洞透进来”标【史】，两边都没查到出处；“半埋在地下”和现在的几何（立在抬高的铺地上，北段离地 8 m）也对不上。
10. **暗廊不归任一座宫**：它在 `palatine.js`，两份规划都说要“单独立一项”。在那一项之前，两边门洞的标高都应以 deck 51.52 为准重新对一遍，不要以 49.02 为准。
